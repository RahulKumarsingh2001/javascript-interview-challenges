# JavaScript Interview Challenges 🚀

A collection of **10 JavaScript coding challenges** solved as part of my software development interview preparation. This repository focuses on problem-solving, JavaScript fundamentals, asynchronous programming, and writing efficient, readable code.

My goal is to strengthen my JavaScript skills and prepare for technical interviews for **Software Developer, Frontend Developer, and Full Stack Developer** roles.

## 📚 Challenges Covered

| # | Challenge | Key Concepts |
|---|---|---|
| 1 | Flatten a Nested Array | Recursion, Arrays |
| 2 | Longest Substring Without Repeating Characters | Sliding Window, `Set`, Strings |
| 3 | Two Sum | Hash Map, Array Traversal, Time Complexity |
| 4 | Deep Clone an Object | Recursion, Objects, Arrays, References |
| 5 | Implement Debounce | Closures, Timers, Higher-Order Functions |
| 6 | Implement Custom `Promise.all()` | Promises, Asynchronous JavaScript |
| 7 | Predict Event Loop Output | Call Stack, Microtasks, Macrotasks |
| 8 | Group Employees by Department and Find the Highest Salary | `reduce()`, Objects, Data Transformation |
| 9 | Implement an Async Retry Mechanism | `async/await`, Promises, Error Handling |
| 10 | Implement a Limited-Concurrency Promise Pool | Concurrency, Promises, Asynchronous Control Flow |

## ▶️ How to Run

Make sure [Node.js](https://nodejs.org/) is installed on your system.

1. Clone the repository:

   ```bash
   git clone https://github.com/RahulKumarsingh2001/javascript-interview-challenges.git
   ```

2. Navigate to the project directory:

   ```bash
   cd javascript-interview-challenges
   ```

3. Run any challenge file:

   ```bash
   node FlattenArray.js
   ```
